# 📊 Sales Performance Dashboard | Power BI

## 📌 Project Overview
This project is an interactive **Sales Performance Dashboard** built using **SQL, Excel, and Power BI**. The dashboard helps analyze sales, orders, profit, product performance, category trends, and regional profitability.

## 🎯 Objective
The objective of this project is to transform raw sales data into meaningful business insights through interactive visualizations and KPI tracking.

## 📈 Key KPIs
- **Total Sales:** 77.15M
- **Total Orders:** 10K
- **Total Profit:** 12.73M
- **Average Order Value:** 7.71K
- **Profit Margin:** 16.50%

## 📊 Dashboard Features
- Monthly Sales Trend
- Sales by Category
- Top Products by Sales
- Profit by Region
- Interactive Filters and Slicers

## 🛠️ Tools Used
- SQL
- Excel
- Power BI
